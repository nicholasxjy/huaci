## 行为检查

| 编号 | 检查项 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1 | 无选区按快捷键 | 提示“没有读取到选中的文字”，不发请求 | |
| 2 | 剪贴板有图片时触发 ⌘C 回退 | 取词后图片仍在剪贴板 | |
| 3 | 剪贴板有富文本（多类型）时触发回退 | 取词后粘贴格式不变 | |
| 4 | 剪贴板为空时触发回退 | 取词后剪贴板仍为空 | |
| 5 | 选中图片（无文字）触发回退 | 提示无可翻译文字，剪贴板恢复 | |
| 6 | 中文单词 / 中文句子 | 译成英文；单词显示词典样式 | |
| 7 | 英文单词 / 短语 / 句子 / 长段落 | 译成简体中文；长段落可滚动 | |
| 8 | 日文、法文等其他外文 | 译成简体中文 | |
| 9 | 中英混合 | 按占主导的语言判断方向 | |
| 10 | 连续快速按两次快捷键（不同选区） | 只显示最后一次的结果 | |
| 11 | 翻译中按 Esc / 点击外部 | 浮窗关闭，旧结果不再出现 | |
| 12 | 断网 / 超时 | 显示可理解的错误和“重试” | |
| 13 | 鼠标在屏幕四角、副显示器 | 浮窗完整可见 | |
| 14 | 快捷键改为已被系统占用的组合 | 提示冲突并保留原快捷键 | |
| 15 | 收藏单词后重启应用 | 生词本仍有该单词；历史可搜索、删除、清空 | |
| 16 | API Key 无效、服务地址错误、模型名错误 | 显示可理解的错误；Key 无效或未配置时可直接打开设置 | |
| 17 | 未开启辅助功能权限按快捷键 | 浮窗说明用途并可打开系统设置 | |
| 18 | 自动复制期间，用户再次复制内容 | 保留新剪贴板；版本不明确时停止取词 | |
| 19 | 持续按住快捷键修饰键 | 不发送复制命令，提示松开后重试 | |
| 20 | 已保存 Key 时逐字修改服务地址 | 不自动发送 Key；仅显式刷新或测试时使用当时选择的地址 | |
| 21 | 浏览器登录中取消，然后重新登录 | 清除等待状态，新登录可正常开始 | |
| 22 | 替换登录后，旧浏览器标签页才跳转回来 | 忽略旧 state，当前登录仍可完成 | |
| 23 | 固定浮窗后内容变高，或调整显示器布局 | 浮窗保留可见位置，控件不超出当前屏幕 | |
| 24 | 在浮窗选中译文或例句的一部分，再按 ⌘C | 复制选中部分；无选区时复制完整译文 | |
| 25 | 开启 VoiceOver 或减少动态效果 | 状态可朗读；VoiceOver 提示保留至关闭；加载使用静态替代 | |
| 26 | 使用隔离测试库注入查询、收藏或历史写入失败 | 明确显示错误并可重试；保留译文、已有列表和收藏状态 | |
| 27 | 朗读 A 后立即朗读 B，再收到 A 的结束通知 | B 继续显示停止控件；旧回调不清除 B 的状态 | |

自动化回归与隔离的原生界面截图见 [state-machines.md](state-machines.md)。上表的跨应用、VoiceOver、实际音频与多显示器结果由人工实测填写。
