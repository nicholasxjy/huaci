## 行为检查

| 编号 | 检查项 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1 | 无选区按快捷键 | 提示“没有读取到选中的文字”，不发请求 | |
| 2 | 剪贴板有图片时触发 ⌘C 回退 | 取词后图片仍在剪贴板 | |
| 3 | 剪贴板有富文本（多类型）时触发回退 | 取词后粘贴格式不变 | |
| 4 | 剪贴板为空时触发回退 | 取词后剪贴板仍为空 | |
| 5 | 选中图片（无文字）触发回退 | 提示无可翻译文字，剪贴板恢复 | |
| 6 | 中文单词 / 中文句子 | 译成英文；单词显示词典样式 | |
| 7 | 英文单词 / 短语 / 句子 / 长段落 | 译成简体中文；长段落可滚动 | |
| 8 | 日文、法文等其他外文 | 译成简体中文 | |
| 9 | 中英混合 | 按占主导的语言判断方向 | |
| 10 | 连续快速按两次快捷键（不同选区） | 只显示最后一次的结果 | |
| 11 | 翻译中按 Esc / 点击外部 | 浮窗关闭，旧结果不再出现 | |
| 12 | 断网 / 超时 | 显示可理解的错误和“重试” | |
| 13 | 鼠标在屏幕四角、副显示器 | 浮窗完整可见 | |
